项目里的主要内容

  • 接收题目与测试样例

    监听本机 10045 端口接收 Competitive Companion 题目。

  • 按本地模板创建代码

    保存测试样例，并使用本地 C++ 与 JavaScript 模板。

  • F9 / F10 / F12 编译与测试

    提供编译、运行首组样例及测试全部样例的快捷键。
